# chip8-emulator.
Chip8 emulator with a integreted debugger that can run in any posix terminal.

# Dependencies
Teye 0.4.0 (https://github.com/Paperfox56/teye.git)
2A2A
# Limitations
This code was not made to run in a multithreading system. Never try to pass data from or to it unless you know what you are doing
